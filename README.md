# Proyecto Sitio Web - Ingeniería / Servicios Industriales

Carpeta base para la estructura, diseño y desarrollo del sitio web.

## Estructura del Directorio

- `docs/`
  - `referencias-benchmark.md`: Análisis comparativo de los sitios de referencia (Siemens, Moneleca, Phase, Scadatech, PAC-E, ED América) tanto en arquitectura de información como en UX/UI.
  - `briefings/`: Espacio reservado para agregar la información, documentos, especificaciones o lineamientos facilitados por el cliente.
- `assets/` *(a crear)*: Para logotipos, imágenes de proyectos, esquemas o recursos gráficos.
- `src/` *(a crear)*: Código fuente del sitio (según el stack que elijas: HTML/Tailwind, Astro, Next.js, etc.).
