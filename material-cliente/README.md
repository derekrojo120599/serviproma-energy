# Material del Cliente

Colocá acá todos los archivos que te entregó la empresa para construir el sitio web.

## Estructura de carpetas:

- `branding/`: Logotipos (SVG, PNG alta resolución), manual de marca, paleta de colores, tipografías.
- `documentos/`: Briefings, PDFs corporativos, catálogo de servicios/productos, textos de "Sobre nosotros", fichas técnicas, certificaciones.
- `imagenes/`: Fotos de proyectos reales, instalaciones, maquinaria, equipo de trabajo, sedes.

Copiá los archivos acá y cuando los tengas listos los analizamos para definir la arquitectura y el contenido del sitio.
